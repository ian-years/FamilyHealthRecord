## 阶段 25.1：修复「跨年度资料活动」年份展开整页刷新（用户反馈 bug）

根因：`bindOverview()` 里 `[data-act-toggle]` 点击展开年份时调了 `renderOverview()` 整页重渲染，关注卡/费用卡被重置成「正在载入…」占位再异步拉一遍 → 整页闪一下。

修复：改为就地切换 `.year-grp` 的 `open` class + 「收起/展开月份」提示文字，不再碰 renderOverview。提示文字选择器用 `h.querySelector(':scope > .muted')`（直接子元素），因为「共 X 份资料」那个 .muted 嵌在 .l 里，querySelector 会先命中它。

验证：浏览器实测点击展开/收起零 API 请求、关注卡/费用卡 DOM 长度不变、提示文字正确切换。版本 → v=20260925-2。

教训：`.year-grp.open .months{display:block}` 已由 CSS 控制展开收起，纯 class 切换即可，重渲染是多余且有害的。
