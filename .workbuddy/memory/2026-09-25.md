## 阶段 25.1：修复「跨年度资料活动」年份展开整页刷新（用户反馈 bug）

根因：`bindOverview()` 里 `[data-act-toggle]` 点击展开年份时调了 `renderOverview()` 整页重渲染，关注卡/费用卡被重置成「正在载入…」占位再异步拉一遍 → 整页闪一下。

修复：改为就地切换 `.year-grp` 的 `open` class + 「收起/展开月份」提示文字，不再碰 renderOverview。提示文字选择器用 `h.querySelector(':scope > .muted')`（直接子元素），因为「共 X 份资料」那个 .muted 嵌在 .l 里，querySelector 会先命中它。

验证：浏览器实测点击展开/收起零 API 请求、关注卡/费用卡 DOM 长度不变、提示文字正确切换。版本 → v=20260925-2。

教训：`.year-grp.open .months{display:block}` 已由 CSS 控制展开收起，纯 class 切换即可，重渲染是多余且有害的。

## 阶段 25.2：去掉滚动条旁全局黑色渐变竖条（用户反馈 bug）

根因：`.drawer` 关闭时 translateX(100%) 移出屏幕但没加 visibility:hidden，其 box-shadow(-8px 0 32px) 仍从视口右缘向内画约 40px 暗色渐变，全局每页右侧都有一条，像「黑色渐变背景」。

修复：关闭态 visibility:hidden（transition visibility 0s linear .22s 延迟到收起动画播完），打开态 visibility:visible（0s 立即可见，滑入不受影响）。12 个抽屉共用 .drawer 类，一处修复全局生效。

验证：关闭态阴影不再绘制、开/合动画正常、E2E 231 条 0 失败。版本 → v=20260925-3。

教训：off-canvas 元素（translateX/Y 出屏）必须配 visibility:hidden，否则阴影/内容仍参与绘制与焦点。

## 阶段 26：异常指标视觉区分

需求方确认口径：判据=原文箭头优先 + 无箭头按参考范围比对（两者结合）；颜色不引入红（维持蓝白灰规范）；所有出现位置都要有区别。

实现：
- hrw_indicators.py 新增 parse_reference_range() + abnormal_direction() 纯函数（↑↓HL偏高偏低优先，无箭头解析范围比对，压线=正常，解析不了=None 不硬猜）
- /api/indicators、/api/watched、/api/trend 三接口统一带 abnormal 字段（trend 的 points/line/history 都有）
- 前端四落点：概览关注卡（整行浅蓝底 + .abn 蓝箭头）、指标详情历史记录（.abn 箭头）、趋势图（异常点实心深蓝 r=5，正常空心白）、档案详情/文档详情表（原文纯箭头用 .abn 样式）

踩坑：
1. list_watched 补 last_reference 时 ? 占位符 8 个却传 9 个参数 → sqlite3.ProgrammingError，连环炸 persons/routes 测试。改 SQL 时逐个数占位符！
2. 真实库参考范围有「40--75」双横线写法，单横线正则把第二个 - 当负号 → 解析成 40~-75 翻转 → 大面积误判（17 个异常 10 个假）。分隔符改 [~～\-—]+ 后收敛为 7 个真异常。
3. 验证时改了后端代码必须重启服务进程，curl 复验前先确认进程加载的是新代码。

测试：新增 test_abnormal.py 38 项，Python 合计 355；自检 131、E2E 231、静态守卫全绿。版本 → v=20260925-4。
